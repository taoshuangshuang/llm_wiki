# 知识流程设置实施记录

日期：2026-10-25。记录当前工作区代码与验证结果，不表示已打包或安装新的桌面版本。

## 界面与配置归属

主导航新增「知识流程」，顶部阶段依次为公共设置、文件预处理、分析规划、页面生成、匹配与写入、后台审阅、检索、输出。公共设置和知识使用部分用分隔线区分；检索说明其在入库与审阅中的复用关系，后台审阅说明独立执行。

顶部选择阶段，下方左侧选择执行节点，右侧展示职责、输入、产出、条件、范围及修改影响。无独立配置的页面提交、目录更新、证据融合和回答展示等节点仍然可见。主阶段与节点标记未保存修改；切换节点保留草稿，切换项目重建草稿。

参数保存只提交当前节点。模型、检索、外部搜索沿用现有即时持久化表单；项目文件通过单独按钮保存。共用规则只有一个编辑来源，其他节点提供引用与跳转，编辑处列出引用节点。旧审阅迁移只将建议填入统一审阅草稿，不另设保存编辑器。

原应用设置保留启动与关闭、界面、API/MCP、维护、更新日志和关于。模型、网络、文件处理、解析、多模态、向量、检索与输出参数迁入流程页。

## 项目文件

- `purpose.md`、`schema.md`、`page-rules.md`、`business-modules.md` 位于项目根目录。
- 提示词继续放在 `prompts/`，名称与历史别名兼容。
- 根目录独立配置优先于旧 `schema/` 独立文件，再回退旧 Schema 对应章节；空根目录文件表示明确清空对应配置。
- 打开旧项目时，将旧 `schema/` 独立文件复制到根目录；不覆盖已有根目录文件，旧文件保留。迁移失败保留兼容读取并记录错误。
- 新项目生成、原生同步根目录与公共 API 文件枚举同步支持两个根目录配置文件。

流程文件保存通过原生 `save_workflow_file` 人工入口，在提交锁中比较读取版本，记录人工文件历史；限制可写配置路径并检查解析后的项目范围。外部修改时拒绝覆盖。提示词保存校验实际支持的变量及必要协议，模块字典保存校验结构；恢复默认值先进入草稿。

## 研究功能范围

移除研究搜索词默认规则及加载、初始化、注入；旧项目文件不删除，旧模板同名变量清空兼容。移除审阅单项研究、批量研究、历史自定义研究动作，以及审阅会话的研究标签。审阅保留证据核查、会话与普通处理操作，研究建议事项仍可人工审阅。

独立深度研究保留；从审阅场景点击主导航独立研究入口会切到 Wiki 工作区。其余工作区的研究能力不变。
