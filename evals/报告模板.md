# 当前验证报告约定

报告由通用验证器生成到被测 skill 的 `evals/验证报告.html`，保留最新一份；不单独生成 `report.json`，机器结果内嵌在 HTML 的 `validation-data` 节点。

## 总览

- 被测 skill、本次时间、当前内容指纹和实际修改说明。
- 全部 case 的通过、失败、执行错误、待复核和未运行数量。
- 本次通过数 / 全部 case 数；错误、待复核和未运行不计通过。
- 无基线执行，不宣称相对旧版分数提升；原有场景本次通过仅支持已覆盖范围的判断。

## 每个 case

- 实际状态和耗时、可观测用量，缺失指标明确未知。
- 验收方式：复用原有验收脚本，或独立模型复核。
- 每条检查的名称、是否关键、结论、证据摘录与相关文件链接。
- 对话、实际交付物，以及非通过时按需保留的错误日志和执行记录。
- 输出未成功保存时显示执行错误，不链接旧输出冒充本轮结果。

## 判定

关键项失败则 case 失败；关键项全部通过才通过；没有关键项或关键项证据不足则待复核。执行或评分协议错误单列。复核依据原 skill 和用户请求，不强制复制完整验收文件；模型判断不等同于确定性事实证明。

成功只保留用户可见对话与实际产物；完整执行事件仅临时用于核对过程，报告保留必要摘录。报告提供“全部 case”和“仅看未通过”筛选。

## 版本记录

`版本变更记录.md` 追加本次内容指纹、实际修改说明和结果摘要。旧产物与旧报告不归档，也不把历史条目链接到已被覆盖的新报告。
