# 缓存条目表说明

本资料说明 `cache_entry` 表的物理结构及字段含义。

```sql
CREATE TABLE cache_entry (
    cache_key VARCHAR(64) NOT NULL,
    payload TEXT NOT NULL,
    expires_at BIGINT,
    created_at BIGINT NOT NULL,
    PRIMARY KEY (cache_key)
);
```

| 字段 | 含义 |
| --- | --- |
| cache_key | 缓存条目的唯一键。 |
| payload | 条目存储的文本内容。 |
| expires_at | 过期时间戳；为空表示未设置过期时间。 |
| created_at | 创建时间戳。 |

本资料仅描述表结构，不说明缓存淘汰算法、同步机制或业务接入步骤。
