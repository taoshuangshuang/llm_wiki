# 示例知识库规范

## Page Types

| Type | Directory | Purpose |
| --- | --- | --- |
| topic | wiki/topics/ | 主题总入口，说明主题定义、用途和基本组成。 |
| concept | wiki/concepts/ | 术语、分类、区别与联系等概念说明。 |
| data-model | wiki/data-models/ | 表、字段、键、索引及存储关系。 |
| constraint | wiki/constraints/ | 独立的使用规范、限制及能力边界。 |

按正文主要用途选择类型。来源摘要使用应用约定的 `type: source`，放在 `wiki/sources/`；应用维护导航，日志沿用原协议。
