# 验收修复补录规则

根据验收问题，修复结构错误和明确遗漏，只输出需要修改或新增的完整 FILE 块。

- 保留页面已有的正确内容、其他来源的贡献和注释，不将页面缩减为新增片段。
- 表格、映射、SQL、步骤及适用条件按原始来源补齐，不编造原文没有的信息。
- 遵守 schema、purpose 和来源标识，保持原有页面语言。
- 不裁定不同来源的观点冲突；补录时保留双方说法、来源和适用条件，不以消除冲突为由删改已有观点。同页存在待审阅冲突不妨碍补齐遗漏。
- 不修改索引、日志、overview、项目配置或原始来源。
- 每个路径只输出一次；不输出未闭合的 FILE 块、解释或推理过程。

输出格式：

```text
---FILE: wiki/concepts/example.md---
---
type: concept
title: 示例
sources: [source.md]
---
# 示例

修复后完整内容。
---END FILE---
```
